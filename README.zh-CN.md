# 无障碍守护 · a11yguard2

> 给读屏用户的手势守护工具。**不用看屏幕**就能把掉线的无障碍服务切回来。

## 解决的痛点

读屏软件突然不说话了，用户想恢复它，得先看得见屏幕去系统设置里操作——但正是读屏失效导致看不见屏幕。这个死循环，本应用来打破。

## 两大能力

### 1. 保活

无障碍服务被系统清理后自动拉回，无需用户干预。界面实时显示成功 / 失败 / 启动 / 重启 / 拉活次数。

### 2. 手势切换

五种手势，都**不需要看屏幕**：

| 手势 | 怎么用 | 熄屏 |
|------|--------|------|
| **音量键双击** | 上 / 下键各绑一个目标服务 | ✅ |
| **距离感应挥手** | 屏幕上方扫手 1–3 次 | ✅ |
| **抬腕** | 拿起手机转向自己 | ✅ |
| **摇一摇** | 甩动手机 1–4 次 | 看机型 |
| **背面敲击** | 敲背面 2–3 次 | 看机型 |

每个手势都能单独设置：开关、目标服务、次数、时间窗、灵敏度、冷却时间。

## 快速上手

```
1. 安装并打开
2. 系统设置 → 辅助功能 → 打开本应用两个服务
   （GuardA11yService 负责保活，TapAgentService 负责手势）
3. 应用内「手势」页 → 给每个手势选目标服务
4. 打开需要的手势开关
```

**注意**：「点按代理」不打开，所有手势都不生效——传感器监听挂在它上面。

## 常见问题

**Q：手势识别到了但服务没切换？**

检查是否选了「目标服务」。手势和音量键一样，识别成功后要执行 `Triggers.runAction()` 去切换，目标为空就什么都不做。

**Q：熄屏后摇一摇不灵？**

部分机型的加速度计是 Non-wakeup 型，深度睡眠时收不到样本。改用**音量键**或**距离感应挥手**，这两个熄屏可用。

**Q：为什么距离感应不会因为贴耳打电话误触发？**

因为一次挥手必须「NEAR 持续够久 + 回到 FAR」才算。贴耳时 NEAR 一直不回 FAR，永远不算一次挥手。

**Q：读屏和本应用会不会冲突？**

不会。本应用不朗读任何内容，只做服务保活和服务切换。
